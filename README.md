#  Business Intelligence Sales Analysis

## Project Overview

This project presents a Business Intelligence analysis of company sales and profitability performance using Microsoft Power BI.

The purpose of the project was to transform sales data into meaningful business insights that can support management decision-making. The analysis examined sales, profit, regions, customer segments, product categories, individual products, and performance trends over time.

## Business Questions

The analysis aimed to answer the following questions:

- Which regions generate the highest sales and profit?
- Which customer segments contribute the most sales?
- Which product categories perform best?
- Which products generate the highest profit?
- What sales trends can be observed over time?
- What business risks and opportunities can be identified?

## Tools Used

- Microsoft Power BI
- Microsoft Word
- GitHub

## Key Findings

- The **West region** generated the highest sales and profit.
- The **Consumer segment** generated the highest sales.
- **Technology** was the highest-selling product category.
- The **Canon imageCLASS 2200 Advanced Copier** generated significant profit.
- **2017** was the strongest-performing year, with **November** recording particularly strong sales performance.

## Business Recommendations

Based on the analysis, the following recommendations were developed:

1. Increase investment and marketing efforts in high-performing regions.
2. Investigate and improve underperforming regions.
3. Prioritize products that consistently generate strong profit.
4. Develop targeted strategies for key customer segments.
5. Monitor sales and profitability regularly using the Power BI dashboard.

## Project Deliverables

This repository contains the following project deliverables:

## Conclusion

The analysis demonstrates how Business Intelligence and interactive dashboards can transform business data into insights. the findings can help managers identify high performing areas, make more informed data driven decisions
